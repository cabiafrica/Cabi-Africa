# Story 10.4: Campaign Performance Dashboard

**Epic:** Marketing Campaigns
**Status:** Done
**Priority:** Medium

## Description
As a marketing manager, I want to track the performance of my promo codes and notifications, so that I can calculate ROI.

## Acceptance Criteria
1.  **UI Implementation**: A "Campaigns" dashboard in the `admin-panel`.
2.  **Metrics**:
    - Total Promo Codes Redeemed.
    - Total Discount Value Given (Cost).
    - Notification Open Rate (simulated).
3.  **Visuals**: Simple cards or a table showing active campaigns.

- **Frontend**: React component `CampaignDashboard`.
