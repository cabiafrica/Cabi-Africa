# Epic: User Profile Enhancements

**Status:** Planned
**Priority:** Medium

## Description
Enhance the user profile experience for both passengers and drivers to allow for greater personalization, security, and ease of use. This includes advanced profile editing, preference management, and identity verification status visibility.

## Goals
1. Allow users to update more personal details (email, emergency contacts).
2. Implement profile picture moderation or advanced cropping.
3. Add user preferences (language, notification settings).
4. Display verification badges (e.g., "Identity Verified").

## Scope
- Passenger App Profile Screen
- Driver App Profile Screen
- Backend User Service updates
