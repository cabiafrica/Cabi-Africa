# Epic: Marketing Campaigns

**Status:** Planned
**Priority:** Medium

## Description
Enable the marketing team to run targeted campaigns to acquire new users and retain existing ones. This includes a referral system, promo code management, and targeted push notifications.

## Goals
1. Boost user acquisition via viral loops (referrals).
2. Increase retention through targeted offers.
3. Provide measurable ROI on marketing activities.

## Scope
- Admin Panel: Campaign Dashboard.
- Backend: Promotion Service, Notification Service.
- Apps: Referral UI, Promo Code Entry.

## Key Stories
- User Referral System
- Admin Promo Code Management
- Targeted Push Notifications
- Campaign Performance Tracking
