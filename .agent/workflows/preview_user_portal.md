---
description: Preview User Portal Application
---

1. Navigate to the User Portal directory.
   ```
   cd apps/user-portal
   ```
   // turbo
2. Install dependencies.
   ```
   npm install
   ```
   // turbo
3. Start the development server.
   ```
   npm run dev
   ```
   // turbo
4. Open the application in a browser (default http://localhost:3000).
   ```
   start http://localhost:3000
   ```
   // turbo
