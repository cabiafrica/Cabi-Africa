# Sprint Plan: Core Trust & Experience

**Author:** Sarah (po)
**Date:** 2024-08-12

**Sprint Goal:** Enhance user trust and platform integrity by delivering critical compliance, accessibility, and fairness features, while also launching high-impact improvements for both driver and passenger experiences.

---

## Committed Stories

This sprint focuses on a mix of compliance, foundational experience, and high-value features.

1.  **`user-account-management.story-140.1-self-serve-account-deletion.yml`**
    - **Title:** Implement Self-Serve Account Deletion
    - **Justification:** Critical for regulatory compliance and user trust.

2.  **`web-and-accessibility.story-46.4-screen-reader-support.yml`**
    - **Title:** Implement Screen Reader Support
    - **Justification:** Foundational accessibility work to make our app inclusive for all users.

3.  **`scheduled-rides.story-22.1-passenger-create-scheduled-ride.yml`**
    - **Title:** Allow Passenger to Schedule a Ride for a Future Time
    - **Justification:** Critical prerequisite for dispatching scheduled rides (`story-22.2`). Pulled into the sprint to unblock development.

4.  **`scheduled-rides.story-22.2-dispatch-scheduled-rides.yml`**
    - **Title:** Implement Backend System to Dispatch Scheduled Rides
    - **Justification:** Core backend logic to make the entire scheduled rides feature functional.

5.  **`driver-engagement.story-62.12-driver-destinations.yml`**
    - **Title:** Implement Driver Destination Filter
    - **Justification:** A highly requested feature to improve driver satisfaction and retention.

6.  **`tipping-features.story-31.3-round-up-to-tip.yml`**
    - **Title:** Implement "Round Up to Tip" Feature
    - **Justification:** A low-effort, high-impact UX enhancement for passengers and drivers.
